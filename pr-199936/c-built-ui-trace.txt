Conclusion
----------
In the shipped desktop Control UI the row-level copy button is gated out by
presentation === "desktop" (pre-existing behavior; C neither adds nor
removes that gate), so a live click-proof of C's call site in the built UI
is infeasible. This trace documents: (1) the gate chain, with live DOM
evidence (Finding 1); (2) that C's diff is byte-for-byte contained in the
served bundles (Finding 2); (3) a live component-level clipboard proof of
the call site (Finding 3, published); and (4) a live built-UI demonstration
that the pre-existing detail-panel surface copies absolute paths
(Supplement).
